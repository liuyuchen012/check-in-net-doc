快速开始 ​

整个过程分五步：开通机构 → 登录后台 → 建班级与学生 → 教室端签到 → 家长绑定。 考试阅卷是第五条链路，按需启用。

一、开通机构（学校 / 培训机构） ​

  1. 打开平台地址 https://agorain.615mc.cn，在登录页选择机构注册
  2. 填写机构名称、管理员账号（邮箱 + 密码），完成邮箱验证码校验
  3. 注册成功后即创建一个独立区域；把区域名称或邀请链接发给平台方，获取 AGRR- 激活码
  4. 在「授权管理」页输入激活码完成激活与续期

未激活区域限制

未激活的区域仅主账号可登录，其余成员无法登录，且受控功能（AI、阅卷、答题卡、设备注册、 课表、子用户、家长邀请）统一停用。

二、登录后台 ​

  • 登录名格式：用户名@区域（主区域为 @manager，不写 @ 时按主区域处理）
  • 首次登录后进入控制台，左侧导航：仪表盘 / 班级 / 学生 / 设备 / 课时 / 通知 / 资源 / 试卷 / 答题卡 / 用户 / 授权 / 设置
  • 管理员在「用户」页可以创建子账户并分配角色（owner / teacher），权限点矩阵统一控制

三、建班级、加学生 ​

  1. 「班级」→ 新建班级，设置年级与名称
  2. 「学生」→ 批量粘贴或逐个添加学生，可生成学号条码
  3. 「学生」→ 批量生成 6 位家长邀请码，导出 CSV 打印发放

四、教室端签到 ​

  1. 桌面端首次启动会进入向导：选择班级、网格行列、启动场景（大屏 / 控制 / 教师）与主题
  2. 大屏模式下，教师在后台创建签到码（教室 / 科目 / 签到密码 / 有效期）
  3. 学生用 App 扫码或输入短码签到 → 结果实时出现在大屏，前三名金 / 银 / 铜高亮
  4. 断网时大屏仍可本地打卡，网络恢复后自动同步

控制模式与教师模式默认内嵌服务端 Web 面板，课时、排课、点名等操作在同一个后台完成。

五、家长绑定 ​

  1. 家长微信搜索小程序，或在教师处扫描小程序码
  2. 选择「绑定孩子」，输入教师发放的 6 位邀请码
  3. 绑定成功后可查看通知（带已读回执）、成绩概览（学校开启后可见）、值日安排与班级资源， 也可以直接给老师留言；多孩家庭可在「我的」中切换孩子

六、第一次考试（可选） ​

  1. 「试卷」→ 新建试卷 → 录入题型与分值；或文件导题（上传 docx / pdf 由 AI 识题）
  2. 「答题卡」标签页配置版面（纸型、考号类型、分区、栏数），预览后打印
    • 也可按班级批量生成一人一张带条码的答题卡
  3. 作答后拍照上传（App 或网页端「动态扫卡」，可接高拍仪）
  4. 客观题本机判分，主观题 AI 批改 → 教师在批改页逐题复判 → 确认出分
  5. 「成绩」页查看总分与得分率分析，需要时导出 CSV

七、常见配置 ​

配置位置说明
AI 服务后台 → AI 设置可自配 API 地址与密钥（OpenAI 兼容协议）；也可使用平台额度
平台 AI 额度后台 → AI 设置兑换 AGRT- 额度码；自配密钥不受额度限制
图像外发开关后台 → AI 设置关闭后不向第三方发送任何作答图像
远程存储服务端配置（运营方）答题卡原图与资料 AES-256-GCM 加密上传 WebDAV
区域功能开关主区域 → 区域管理按区域开关 7 项能力
