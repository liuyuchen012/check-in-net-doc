常见问题 ​

账号与激活 ​

登录后约 1 秒提示「登录已过期」并跳回登录页 ​

服务端签发的令牌必须是合法 JWS（恰好两个点）。若服务端日志出现 IDX14122: JWT is not a well formed JWE, there are more than four dots， 说明令牌生成方式不对：应使用 JsonWebTokenHandler().CreateToken(...)， 而不是 new JwtSecurityToken(...).ToString()（后者在新版本库中返回调试字符串）。

快速自检：登录拿到 token 后 tr -cd '.' | wc -c 数点数，合法 JWS 恰好 2 个。

区域未激活，成员登录不了 ​

未激活区域仅主账号可登录，其余成员被拒绝，且受控功能全部停用。请主账号在 「授权管理」页输入平台方颁发的 AGRR- 激活码完成激活或续期。

忘记管理员密码 ​

在登录页选择「忘记密码」，通过邮箱验证码重置（需服务端已配置 SMTP）。

管理面板 ​

打开某个页面提示 404（例如 /license） ​

管理面板是 history 路由 SPA，反向代理需要回退到 index.html。宝塔/nginx 里若有安全规则拦截 LICENSE、README.md 等关键词（大小写不敏感），会误伤 /license 路由；把 SPA 路由块放到 安全规则之前即可，详见 部署指南。

页面改了但浏览器里还是旧的 ​

管理面板内置过期自愈：启动时会比对线上资源 hash，发现不一致则提示并自动刷新。 若仍异常，请 Ctrl + F5 强刷一次（旧标签页内存里永远是被加载时的旧 JS）。

点了「下载 / 导出」没有反应或提示无权限 ​

下载类接口在新标签页中无法携带 Authorization 头，前端会自动把令牌拼到下载地址上 （?token=）。若代理或网关剥离了查询串，请检查反向代理配置。答题卡打印页是匿名接口， 带 ?download=1 会直接触发附件下载。

扫卡与答题卡 ​

扫卡提示「摄像头打开失败」 ​

  1. 先看页面上的错误名：NotAllowedError = 权限未授予，NotReadableError = 设备被占用/推不出帧
  2. 手机 App 内嵌页面需要宿主 WebView 把相机权限回调转发给网页（MAUI 侧需在 WebViewHandler.Mapper.AppendToMapping 中装回授权 Client）
  3. 网页端动态扫卡按屏幕方向记住可用分辨率档位，切换屏幕方向后会自动重开摄像头

扫卡「切图失败」或总显示第一页 ​

服务端会按页码框 → 二维码 → 落盘文件名 → 版面环匹配的顺序判定页序， 只有客观题页才参与版面校验。请确认：打印时未被缩放（100% 原始尺寸）、 页面四角定位标记完整、纸型与后台配置一致。

答题卡打印后跨页错位 / 页码标记跑到别页 ​

必须使用服务端精确分页的答卷：每张物理页是固定高度容器（277mm）且自带定位标记与页脚。 打印时关闭浏览器自带的「页眉页脚」，缩放选择 100%，纸张与后台配置的纸型一致。

阅卷与出分 ​

上传后一直没出结果 ​

长耗时的识别任务在服务端后台执行（HTTP 立即返回 202，前端轮询结果）。可在 「AI 设置 → 调用日志」查看每次调用的状态、耗时与原始响应。

AI 批改结果为空或 JSON 解析失败 ​

推理型模型（DeepSeek-R1 / Mimo 等）会先输出思考过程，容易顶满 max_tokens 被截断。 平台已做三层处理：提示词要求直接输出 JSON、返回内容做去思考区与括号配对提取、 以及解析失败自动追问一次。若仍频繁失败，可降低单次图片数量（分批识别）或改用更强的视觉模型。

客观题判分与预期不一致 ​

客观题以本地涂卡识别结果为准（零 token）。若答题卡被旋转、缩放或涂抹过浅，识别会失败并 转人工。可在后台把该题设为「教师手判」。

AI 提示「额度不足」 ​

机构使用平台 AI 时按 token 扣减额度（余额以人民币计价）。请在「AI 设置」页兑换 AGRT- 额度码；机构自配 API 密钥则不受额度限制。

数据与存储 ​

服务端启动报 SQLite Error 14: unable to open database file ​

数据库文件所在目录不存在或不可写。SQLite 只创建文件不创建目录， 请 mkdir -p <程序目录>/data && chown -R www:www <程序目录>/data （或在 appsettings.json 的 Data:Directory 指定其它可写目录）。

远程存储怎么工作的？会不会丢文件 ​

答题卡原图与教学资料使用 AES-256-GCM 认证加密后上传 WebDAV 远程磁盘，按区域分目录； 服务器只保留 LRU 缓存，且只淘汰已确认上传成功的本机副本，远程不可用时排队补传。

关闭 AI 图像外发后会发生什么 ​

关闭后，平台不会向任何第三方大模型发送作答图像：客观题仍由本地识别判分， 主观题转为教师人工批改（或使用本地识别能力）。该开关在「AI 设置」中按机构控制。

其他 ​

桌面端在 Windows 10 上启动即报错 ​

.NET 10 在部分 Windows 10 上默认 CET 检查会致命报错，v4 已统一设置 CETCompat=false， 请使用官方发布包（自包含）运行。

一体机插件收不到呼叫 / 课表 ​

插件接口为 api/calls_register、api/calls_pull、api/calls_ack 与 api/profile_pull （无 /v4 前缀，密码鉴权）。课表推送后，插件需升级到支持 profile_pull 的版本才会消费服务器档案。 详见一体机联动。

想回到旧版本 ​

v3.2 及更早版本的文档已归档：v3.2 · v2.8 · v2.7。 注意 v4 与旧版本的数据结构不同，升级前请备份 data/ 目录。

还有问题？ ​

请附上：页面截图 + 服务端日志对应时间片段 + 操作步骤。 运维排查入口依次是：/api/v4/setup/status 健康检查 → 服务端日志 → AI 调用日志。
