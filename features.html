功能特性 ​

AgoraIn v4 是课堂签到与班级教学管理一体机平台：一套服务端服务多所机构，桌面端断网可用， 识别在本机完成（零 token），数据按机构隔离。

产品形态：服务端（Linux）+ 桌面端（Windows）+ Web 管理面板 + 移动端 App + 微信小程序家长端。

一、课堂日常 ​

扫码签到 ​

  • 教师生成签到码（教室 / 科目 / 签到密码 / 有效期），学生在 App 扫码或输入短码完成签到
  • 签到结果经实时通道推送到同班大屏，前三名金 / 银 / 铜高亮
  • 打卡数据支持导入导出（CSV），大屏网格行列可配置

课时管理 ​

  • 课时账户与划消流水：划消、赠送、备注，按班按人可查
  • 与课程表联动：上课下课自动切换场景，课时自动扣减（幂等，不重复扣）

点名 / 积分 / 值日 / 座位 ​

功能说明
点名随机加权（近期没点过的优先）/ 顺序 / 指定三种场次；答到 · 缺勤 · 迟到，可联动积分
积分规则（每日上限、适用班级）、流水（手工 / 打卡 / 点名 / 值日 / 答题卡 / 修正）、积分榜；教师修正须填原因并留痕
值日岗位（名称 / 图标 / 人数）、按周或按日轮换生成值日表、完成情况记录
座位布局编辑（行列、讲台方位、禁用空位、分组）、拖拽调座、一键随机换座（自动留存快照）

课程表 ​

  • 科目 / 作息 / 班级课表维护，支持导入导出 ClassIsland 档案（JSON / YAML）
  • 一键推送到教室一体机（ClassIsland 插件同步）

通知与资源 ​

  • 班级通知支持定时发布，家长端带已读回执统计
  • 教学资源上传 / 预览 / 下载，并按需下发家长端

设备集控 ​

  • 打卡设备注册、绑定、心跳与在线状态；控制模式可打开集控 Web 面板

二、考试与阅卷（完整闭环） ​

出卷 → 生成答题卡 → 打印 → 作答 → 拍照上传 → 识别 → 批改 → 成绩统计

出卷 ​

  • 6 种题型：单选 / 多选 / 判断 / 填空 / 简答 / 作文；分值、标准答案、评分要点、知识点标签
  • 文件导题：上传 docx / pdf / txt 由 AI 自动识题（题目与答案可同一文件，也可分「试卷 + 答案」两个文件）
  • 缺答案的题可 AI 生成答案批量补齐；题库模板可复用

答题卡 ​

  • 纸型：A4 / B4 / 8K / 16K / A3 五种；8K / A3 横向一版两页，一张纸拍一次两页同时识别
  • 服务端精确分页：每页独立定位标记 + 页码标定框 + 页脚二维码，多页答卷自动归并且不串页
  • 考号涂卡或条码；可按班级批量生成一人一张带条码的答题卡
  • 作文纸：语文格子纸（8mm 格 × 20 列）与英语深色横线纸（行距可调），后台可视化拖拽改版式
  • 客观题 OMR 采用标准方形框（6 × 4 mm），选项间距 2 mm

扫卡与识别 ​

  • 扫卡入口：手机 App 拍照、网页端「动态扫卡」（可接高拍仪）
  • 扫完即进后台识别队列，前台继续扫下一张；扫卡有准入闸门（认不出不落库）
  • 客观题涂卡识别：本机完成，零 token
  • 填空短答案手写识别：本地模型，精确匹配才自动给分
  • 主观题：多模态模型按评分要点批改；作文按维度点评
  • 识别成本可控：只有判不准的才交给 AI 或人工

批改状态机 ​

未批 → AI 已批 →（低置信度）待人工 → 已确认

  • 逐题对话框可查看识别内容与 AI 建议分，支持快捷记分键与全屏批改
  • 只有「已确认」计入成绩；客观题可设为教师手判
  • 支持双判（两位教师独立评分取平均、超阈值转仲裁）与分题阅卷分配

成绩统计 ​

  • 按学生总分与按题得分率分析，CSV 导出（Excel 直接打开）
  • 教师复判与改分全部留痕可追溯

手写数据自闭环（平台侧能力） ​

平台可生成训练卡 → 学生誊抄 → 扫回自动切行 / 切单字 → 本地 OCR 自动判定哪些样本可用 → 抽查纠正 → 导出训练集，用于持续微调自有手写识别模型。数据越攒越准，成本越用越低。

三、家校沟通 ​

  • 家长端小程序与移动端 App 功能对等：通知与已读回执、班级资源、考勤 / 积分 / 值日、 成绩概览（受隐私开关控制，默认关闭）、与教师留言；支持多孩切换
  • 绑定方式：教师端按班级批量生成 6 位邀请码（可导出 CSV 打印发放），家长输入即绑定
  • 留言沟通留痕，不再依赖家长群刷屏

四、平台运营（多区域 / 租户） ​

能力说明
机构自助注册机构注册后由主区域颁发 AGRR- 激活码开通；未激活前成员无法登录，受控功能全部停用
区域隔离班级、学生、打卡、课表、试卷、成绩等全部按区域过滤；登录名格式 用户名@区域
区域功能开关按区域开关 7 项能力：AI 功能 / 阅卷与出分 / 答题卡识别与批改 / 设备注册 / 课表管理 / 子用户 / 家长邀请
AI 额度主区域颁发 AGRT- 额度码，机构兑换入账；机构也可自配 AI 密钥，不受额度限制
加密远程存储答题卡原图与教学资料以 AES-256-GCM 加密后经 WebDAV 上传远程磁盘，按区域分目录；服务器只保留 LRU 缓存
分级权限admin / owner / teacher / student / parent 五级角色 + 24 个权限点矩阵
离线授权RSA 签名激活码，支持设备数量与到期时间
安装包分发官网安装包由平台统一分发（/api/v4/downloads），单连接限速 + 并发保护，附 SHA256 校验

五、多端形态 ​

端技术栈说明
服务端ASP.NET Core 10 + SQLiteREST + SignalR + JWT，内置本地识别（OMR / 手写 OCR）
桌面端Avalonia 11大屏 / 控制 / 教师三模式，Windows 优先，断网可用
Web 管理面板Vue 3 + Vite20 个功能页，服务端托管
移动端 App.NET MAUI学生扫码签到、教师拍照扫卡与逐题改分、家长中心
家长端小程序微信小程序通知、成绩、值日、留言

六、差异化亮点 ​

  1. 本地优先、离线可用：桌面端断网照常打卡；客观题涂卡与填空短答案都在本机识别
  2. 识别成本可控：该校对的本地核对掉，该校准的才调模型
  3. 一张纸管到底：服务端精确分页 + 页码标定框 + 页脚二维码，多页答卷自动归并且不串页
  4. 一套系统服务多个机构：多区域隔离、功能开关、激活码与额度码，权限边界在服务端
  5. 隐私与合规先行：AI 图像外发开关（关闭后不向第三方发送任何作答图像）、境内存储、 远程文件认证加密、未成年人信息保护专章
