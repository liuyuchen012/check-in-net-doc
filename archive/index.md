## 为什么归档

v4 是一次全量重构：桌面端改为 Avalonia、服务端改为多租户架构、界面与数据模型都换了。
旧版本的文档描述的界面与接口在 v4 上并不适用，因此单独存放，避免与现行文档混淆。

- **想升级**：先看 [快速开始](/guide) 与 [部署指南](/deploy)；
- **想查旧接口**：v3.2 及更早的 API 与 v4 的 `/api/v4/*` 不兼容，仅作参考；
- **想找开源代码**：v3.2 及更早版本以 GPLv3 开源，许可边界见 [开源许可声明](/license)。
