v3.2 归档文档 ​

本区为 AgoraIn v3.2（AgoraInPro） 的历史文档，仅作留存与迁移参考。 新版本请访问 AgoraIn v4 官网（课堂签到与教学管理一体化平台）。

v3.2 是什么 ​

AgoraIn v3.2 在一个窗口内提供大屏模式（课堂签到打卡）与控制模式（呼叫面板、课时划消与排课、 集控平台），配套集控服务器与移动端 App，并提供 ClassIsland 联动插件：教室一体机接收教师端呼叫， 以置顶弹窗 + 中文语音朗读提醒。

模块说明
大屏模式班级电子白板大屏签到，点击学生姓名完成打卡，前三名金 / 银 / 铜高亮
控制模式呼叫面板（待下课 / 应急 / 传唤）、课时划消与排课、集控平台
集控服务器多设备数据集中管理，Web 管理面板，平台配置持久化自动重连
ClassIsland 插件一体机端接收呼叫，置顶弹窗 + 中文语音朗读
移动端微信小程序 + Android + iOS / macOS 客户端

技术栈：桌面端 WPF（.NET 10）· 移动端 .NET MAUI · 服务端 ASP.NET Core · 数据库 SQLite。
