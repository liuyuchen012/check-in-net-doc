🧩 连接插件端（ClassIsland 一体机） ​

本文档对应 AgoraIn v3.2。插件端即运行在 ClassIsland 2.x（教室一体机/电子白板）上的联动插件，用于接收教师端发送的呼叫并置顶弹窗 + 中文语音朗读。

插件端是什么 ​

AgoraIn.ClassIslandPlugin（2.1.1.0）运行在 ClassIsland 主程序进程内，定时向集控平台轮询本机待处理呼叫：

呼叫类型触发方式
⏰ 待下课时段通知结合 ClassIsland 课表，在「距下课 ≤ 提前分钟数」的窗口内自动弹出（蓝色）
🚨 上课应急通知立即弹出（红色）并朗读
📢 下课传唤立即弹出（橙色）并朗读，附传唤学生名单

TIP

测试呼叫请使用「上课应急通知」或「下课传唤」，两者立即弹窗；「待下课时段通知」只在临近下课窗口触发，是设计行为而非故障。

环境要求 ​

  • 教室一体机：Windows 10/11，安装 ClassIsland 2.x
  • 已部署并运行的 AgoraIn 集控服务器（部署指南）
  • 教师端已连接该服务器（「控制模式 → 集控平台列表」）

第一步：安装插件 ​

  1. 在下载中心 Windows 页签下载 ClassIsland.Plugin.cipx（约 353 KB）
  2. 打开 ClassIsland → 设置 → 插件管理 → 本地安装，选择该 cipx 文件（已装旧版请先卸载）
  3. 重启 ClassIsland，确认顶部日志出现：此次会话已加载插件:AgoraIn 联动插件(agorain.classisland,2.1.1.0)

第二步：配置连接 ​

进入 ClassIsland → 设置 → 插件设置 → AgoraIn 联动，填写三项（或点 自动探测 读取本机大屏客户端配置）：

配置项填写内容
集控平台地址http://服务器IP:5250（如 http://192.168.31.3:5250）
连接密码与服务器 config.json 的 ServerPassword 一致（默认 admin123）
设备 UUID必须填写教师端「控制模式 → 设备列表」中该一体机对应的 UUID

WARNING

设备 UUID 是三项中最容易出错的一项。 教师端发送呼叫时按设备列表选择目标，只有 教师端发送目标 == 插件端设备 UUID 时才会收到呼叫。 UUID 即大屏客户端的 client_uuid.txt 内容；如果本机没有大屏客户端，请先在教师端设备列表确认该一体机记录再填写。

保存后插件自动重启轮询：3 秒后开始、此后每 10 秒一次（可在设置页调整 5–120 秒）。

第三步：验证连接 ​

  1. 教师端「控制模式 → 设备列表」中选中该一体机 → 发送到所选 → 选「上课应急通知」并填写标题
  2. 等待约 15 秒，一体机应弹出置顶窗口并朗读：上课应急通知，<标题>…
  3. 校验服务器数据库（可选）：该呼叫记录状态变为 acknowledged 说明插件已拉取并确认
SELECT Id, Title, Status FROM Calls ORDER BY Id DESC LIMIT 5;
-- Status = acknowledged 表示插件端已收到并显示

常见问题 ​

收不到呼叫 ​

  • UUID 不一致（最常见）：确认插件设置与教师端发送目标为同一台设备
  • 插件未启动：确认日志出现 已加载插件；轮询依赖网络，一体机需能访问服务器 5250 端口
  • 呼叫已过期：calls_pull 会把超过 2 小时的 pending 呼叫标记为过期

弹了但不朗读 ​

  • 新版 2.1.1.0 已内置朗读（System.Speech），请先升级插件
  • 系统还原语音：Windows 设置 → 时间和语言 → 语音，确认已安装中文语音（如 Microsoft Huihui）

待下课通知迟迟不弹 ​

  • 「待下课通知」只在距下课 ≤ 提前分钟数时触发；ClassIsland 当前无课表数据时视为立即触发
  • 可临时改发「应急/传唤」验证链路

插件设置不生效 ​

  • 每项修改后记得点 保存（会重启轮询）
  • 配置文件位置：ClassIsland数据目录\Config\Plugins\agorain.classisland\settings.json
