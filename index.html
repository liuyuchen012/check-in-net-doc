产品能力

一所学校要跑的系统，其实是一件事

面向中小学、培训机构与托管班：教师、班主任、教务、家长与平台运营方各有一块自己的界面， 权限边界在服务端。下面是它实际长什么样。

# 课堂日常

签到、点名、课时、积分、值日、座位、课表，一个后台全管

教师生成签到码，学生扫码或输码，签到经实时通道推上班级大屏，前三名金 / 银 / 铜高亮；课时划消留流水，点名支持随机加权，换座拖拽即生效。这些动作都在同一个后台里，数据落到同一张表。

扫码签到
签到码带教室、科目、密码与有效期，扫码即上屏
课时划消
账户 + 流水，谁欠课、欠多少一眼看清
随机点名
近期没点过的优先，答到 / 缺勤 / 迟到可联动积分
积分留痕
手工修正必须填原因，改不掉，可回溯到具体一次操作
/dashboard
实时上屏 · SignalR
# 考试与阅卷

出卷到成绩统计，一条闭环跑完

六种题型出卷，可上传 docx / pdf 由 AI 自动识题、补答案；答题卡支持 A4 / B4 / 8K / 16K / A3 五种纸型，服务端精确分页，多页答卷自动归并且不串页。手机拍照、高拍仪、带进纸器的扫描仪都能扫卡，扫完进后台识别队列排队处理。

五种纸型
每页独立定位标记 + 页码标定框 + 页脚二维码
批量生成
按班级一人一张带条码，扫完自动归属到人
本机判分

# 班级监视

屏幕和摄像头，两路都在

教室端不需要额外装直播软件——桌面客户端自带 ffmpeg，屏幕与摄像头各自推流到服务端，再分发给后台与小程序。屏幕上正在放什么、教室里有没有人，在办公室的浏览器里就能看到。

双路推流
屏幕 + 摄像头同时在线，互不干扰
三层鉴权
登录 + devices.view + HttpOnly 直播 Cookie
切片回放
15 分钟一段，加密落远程磁盘，保留三天
按班查看
设备树按年级、班级、在线状态组织
/monitoring
屏幕 · 摄像头双通道
# 家校沟通

家长端与教师端，同一套数据

班主任按班级批量生成六位邀请码，家长输入即绑定孩子，支持多孩切换。通知带已读回执，成绩概览受隐私开关控制（默认关闭），值日、班级资源、与老师留言都在一个入口里。

v4.5.4 新增

一体机上，只留一个程序

AgoraIn Nexus 把 AgoraIn 的后台服务与 ClassIsland 的课表外壳合成单进程：启动先挂后台， 再把顶栏拉起来，三秒后自动打开工作台。两个程序从此认同一份账号。

  • 一个进程　外壳与后台服务跑在一起，不再有两个托盘图标、两次开机自启。
  • 一份账号　两个程序读写同一个 account.json，登录、换区、退出只做一次。
  • 一个顶栏　课表、倒计时、提醒常驻桌面最上面一条，不占窗口也不挡板书。
桌面顶端 · 常驻顶栏
隐私与合规

数据这条线，能说清楚

教室里的数据不该成为负担。采集范围、存储位置、外发开关，都有明确开关与文档对应。

本地优先

桌面端断网照常打卡；客观题涂卡与填空手写在本机识别，不上传、不花钱。

认证加密

答题卡原图与教学资料以 AES-256-GCM 加密后上传远程磁盘，按区域分目录。

隐私可控

AI 图像外发总开关、成绩默认不对家长开放、未成年人信息保护专章。
