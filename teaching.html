教学模式（希沃式授课台） ​

教学模式的定位：把一节课要用的东西都收在一个页面里 —— 课件、批注、实验演示、教室集控。 老师打开一个网页就能上课，不需要在多个软件之间切换。

进入方式 ​

方式说明
管理面板入口登录管理面板 → 左侧「教学模式」，自动携带登录态打开
登录页直达登录页点「登录并进入教学模式」，登录成功后直接进入教学模式
直接地址https://agorain.615mc.cn/teaching.html?token=<登录令牌>（桌面端 / 移动端内嵌页面同样使用该地址）

页面顶部有 6 个标签页：资源中心 · 白板授课 · 物理实验 · 化学实验 · 集控平台 · 插件； 右上角可选择班级，选中后白板、翻页与实验操作会实时同步给该班级的接收端（学生端 / 教室大屏）。

一、资源中心 ​

上传一次，随时开讲：

  1. 点「上传资源」，选择 PDF / Word / Excel / PPT / 图片（单个 ≤ 200MB）；
  2. 资源以卡片列出：类型、大小、页数、上传人、时间；
  3. 卡片操作：打开授课（进入白板授课并加载该文件）、下载、改名、删除（连同批注一并删除）；
  4. 顶部可按类型筛选（全部 / PDF / Word / Excel / PPT / 图片）。

PDF 与图片在线渲染（PDF 用 pdf.js，中文正常显示）；Word / Excel / PPT 目前不在线预览， 打开后是白板页，可下载原件本地打开 —— 批注、回放、实时同步不受影响。

二、白板授课（批注 + 回放） ​

左侧工具栏：画笔 / 擦除 / 直线 / 矩形 / 椭圆 / 文字，5 种颜色，点「粗细」循环切换线宽。 顶部工具条：上一页 / 下一页 / ＋加页 / 撤销 / 清空本页 / 回放批注 / 全屏 / 下载原件 / 返回资源库。

使用要点：

  • 批注自动保存：每一笔画完即写入服务端（按「资源 + 页」保存），换电脑打开同一资源，批注还在；
  • 回放批注：像希沃一样把本页批注按书写顺序动画重演，适合讲评与复盘；点「■ 停止」可中断；
  • 翻页/加页：PDF 页数自动识别；Office 文档与空白白板可用「＋加页」扩展页数；
  • 实时同步：选好班级后，笔迹、翻页、撤销、清空都会秒级推送到该班级的接收端；
  • 全屏：一键进入全屏授课，退出用 Esc。

三、物理实验（电路沙盘） ​

元件箱里的元件全部为本项目自绘矢量图，不依赖任何第三方实验素材：

元件说明
电池（3V）含内阻，可多节串联
开关点一下合/断
小灯泡按功率发光；功率超限会烧毁
定值电阻默认 10Ω
滑动变阻器选中后用顶部滑块调阻值（0–20Ω）
电流表 / 电压表实时读数

操作流程：

  1. 点左侧元件按钮放到实验台 → 拖动摆位置（自动吸附网格）；
  2. 切到「连线」模式，点两个接线柱生成导线；右键导线可删除；
  3. 「选择/移动」模式下点开关合闸、双击元件或按 R 旋转 90°、选中后「删除选中」移除；
  4. 电路自动仿真：状态栏显示是否导通与干路电流，右侧面板给出电表读数与灯泡功率；
  5. 预设电路一键装载：串联电路 / 并联电路 / 伏安法测电阻。

四、化学实验（仪器 + 药品 + 反应） ​

  • 仪器：试管、烧杯、锥形瓶、集气瓶（最多同时放 6 件）；
  • 药品架：稀盐酸、稀硫酸、大理石、锌粒、过氧化氢、二氧化锰、高锰酸钾、氢氧化钠、硫酸铜溶液、铁钉、酚酞、紫色石蕊、澄清石灰水、水；
  • 操作：先点药品再双击仪器加入 → 选中仪器后「🔥 加热」（酒精灯动画）「✨ 点燃」「🫙 收集气体」「🔥 木条验满」；
  • 反应由规则表驱动，自动给出现象 + 化学方程式，例如：
    • 大理石 + 稀盐酸 → 大量气泡（CO₂）：CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑
    • 锌 + 稀硫酸 → 气泡（H₂）；H₂ 点燃 → 淡蓝色火焰
    • 高锰酸钾加热 → O₂；二氧化锰催化过氧化氢 → O₂
    • 澄清石灰水遇 CO₂ 变浑浊；铁钉浸硫酸铜 → 表面析出红色物质
    • 酚酞遇碱变红、石蕊遇酸变红 / 遇碱变蓝

五、集控平台（对齐 ClassIsland 集控能力） ​

  • 教室端设备：列出所有已登记的教室机（在线状态实时刷新）；目标可选「📢 广播」或指定某台；
  • 指令下发（13 类）：通知弹窗、语音播报、自定义消息、锁定屏幕、解锁屏幕、打开网页、启动应用、结束应用、 推送课表档案、刷新课表、休眠、重启、关机（电源类指令有二次确认）；
  • 指令历史：每条指令显示发送人、时间与执行回执（已执行 / 待执行 + 结果），可据此确认教室端是否真的执行了。

六、插件（可安装插件包） ​

  • 「安装插件包」上传 .agp 包 → 列表里启用 / 停用 / 重载 / 卸载；
  • 已启用且自带界面的插件，会在下方「插件界面」下拉中列出，点开即用（内嵌 iframe）；
  • 服务端集控插件 ClassIsland 集控平台（GPL-3.0） 就是从下载中心取包、在这里安装启用；
  • GPL 系插件安装时需勾选「已知悉开源合规」，且插件包必须声明源码地址 —— 详见开源许可声明。

常见问题 ​

Q：白板批注会丢吗？ 不会。每笔画完即写入服务端（按资源 + 页存储）；换设备、换浏览器打开同一资源仍在。回放只影响显示，不改数据。

Q：学生能看到我的批注吗？ 只有在你选择了班级并保持连接时，白板与实验操作会实时推送到该班级的接收端。不选班级则只在本机显示。

Q：Office 文件为什么不能直接批注在原文上？ 在线渲染 Office 需要服务端转码，目前未启用；建议课前把课件导出为 PDF，就能获得完整批注体验。

Q：实验数据是"真算"的吗？ 物理电路使用**改进节点法（MNA）**实时求解，灯泡亮度、电表读数都来自计算；化学为规则表驱动，覆盖中学常见演示实验。
