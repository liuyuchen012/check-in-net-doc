班级监视 ​

v4.1 新增。每台教室设备提供 2 个端点（屏幕 / 摄像头），支持 3 天回放， 录像按 15 分钟切片后存入 WebDAV。直播层使用开源 livego（MIT）。

需要什么 ​

  • livego：接收 RTMP、分发 HLS/HTTP-FLV；管理 API 只绑 127.0.0.1:8090； v4.1 起随服务端发布目录内置（tools/linux-x64/livego），由服务端自动启动/守护；
  • ffmpeg：服务端从 livego 拉流并切成 15 分钟 MP4；同样内置（tools/linux-x64/ffmpeg），无需目标机安装；
  • WebDAV：在「设置 → 存储」启用，录像上传到 agorain/{区域}/monitoring/...；
  • 设备端推流：被控端客户端内置。教室大屏登录并绑定设备后，客户端自动调用随包 ffmpeg 推屏幕/摄像头，不需要另装推流客户端；monitoring/agent/agent.py 仅作特殊设备备用。

快速配置 ​

json
"Monitoring": {
  "Enabled": true,
  "AutoStartLiveGo": true,
  "UseBundledTools": true,
  "LiveGoApiUrl": "http://127.0.0.1:8090",
  "RtmpBase": "rtmp://<内网IP>:1935/live",
  "HlsBase": "http://<内网IP>:7002/live",
  "FlvBase": "http://<内网IP>:7001/live",
  "FfmpegPath": "",
  "SegmentMinutes": 15,
  "RetentionDays": 3,
  "DeleteLocalAfterUpload": true
}

重启 AgoraIn 服务端（会自动拉起内置 livego），然后用管理面板 「教学日常 → 班级监视」查看设备、直播与回放。

端点与地址 ​

通道推流地址播放
屏幕rtmp://<host>:1935/live/{区域}-{设备UUID}-screenhttp://<host>:7002/live/{流键}.m3u8
摄像头rtmp://<host>:1935/live/{区域}-{设备UUID}-camera同上

服务端提供鉴权接口：

  • GET /api/v4/monitoring/devices：设备与两路流地址、在线状态；
  • GET /api/v4/monitoring/segments：最近 3 天分段；
  • GET /api/v4/monitoring/segments/{id}/file：回放（Range，支持拖动）；
  • GET /api/v4/monitoring/live-session：登录且 devices.view 用户获取 15 分钟直播 Cookie；
  • GET /api/v4/monitoring/live-auth：nginx auth_request 校验。

直播观看必须登录且具备 devices.view；HLS/FLV 每个分片请求都会校验 HttpOnly Cookie，不能把播放地址直接分享给未登录用户。

注意 ​

  • livego 的 HLS 本身不带鉴权，生产应把 7002 限制在内网或反代后；
  • 录像目前不加密存 WebDAV（视频体量大），WebDAV 账号必须专用且最小权限；
  • 15 分钟分段之间会有 1–2 秒空档，不是连续时间轴；
  • 设备端关键帧间隔建议 -g 30，否则切片边界会漂移。
