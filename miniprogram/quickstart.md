# 快速开始（家长）

## 家长：三步绑定

1. **拿到邀请码**：教师在班级里批量生成 6 位邀请码并发放（通常打印在通知条上）
2. **打开小程序**：微信搜索 AgoraIn 家长端，或扫描学校提供的小程序码
3. **输入邀请码**：选择「绑定孩子」→ 输入 6 位邀请码 → 绑定成功

绑定后即可看到通知、值日、班级资源与留言入口；成绩概览需学校开启后可见。

## 教师：怎么发邀请码

1. 后台「学生」→ 选择班级 → **批量生成邀请码**
2. 点击「导出 CSV」拿到全班邀请码清单（含学生姓名），打印后发放
3. 家长绑定后，「学生」列表会显示已绑定的家长数量

::: tip 邀请码规则
邀请码为 6 位、一码一学生、可重复使用于同一孩子的多个家长（父母可各绑一次）。
学生转班或毕业时可在后台作废重建。
:::

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 提示邀请码无效 | 确认是否已作废或输错；请教师重新生成 |
| 看不到成绩 | 学校未开启成绩概览（默认关闭），请联系班主任 |
| 绑定错了孩子 | 在「我的 → 孩子管理」申请解绑，或联系教师处理 |
| 收不到通知 | 检查微信通知权限；小程序内下拉刷新 |
