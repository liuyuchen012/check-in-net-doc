快速开始 ​

  1. 使用 微信开发者工具 导入项目根目录。
  2. AppID 使用 wxa2003db2b4693a66（或替换为自己的测试号）。
  3. 编译基础库选择 3.6.3 及以上。
  4. 若使用签到功能，需准备 AgoraIn 局域网打卡服务器（参考官网部署指南），并在登录页填写服务器地址（支持 mDNS 自动发现）。

注意：miniprogram_npm/ 已包含编译好的 tdesign-miniprogram 依赖，开箱即用，无需额外执行 npm 构建。

Android 安装 ​

  1. 前往 下载中心 获取 Android APK 文件。
  2. 将 APK 传输到 Android 手机（或直接使用手机浏览器下载）。
  3. 点击 APK 安装，如提示"未知来源"请允许安装该应用。
  4. 安装完成后打开应用，若使用签到功能，需保证手机与 AgoraIn 服务器同一局域网。
