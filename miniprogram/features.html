家长端功能特性 ​

首页 ​

  • 孩子信息卡：班级、班主任、今日出勤状态
  • 快捷入口：通知 / 成绩 / 值日 / 资源 / 留言
  • 未读通知与未读留言角标

通知 ​

  • 按时间倒序展示班级与学校通知，支持富文本与附件
  • 已读回执：打开即上报已读，教师端可看谁未读
  • 重要通知置顶

成绩 ​

  • 受隐私开关控制（默认关闭）；开启后可见单次考试成绩与班级区间
  • 支持按科目与时间查看历次成绩走势

考勤与积分 ​

  • 签到记录、请假记录
  • 积分变动流水（打卡 / 点名 / 值日 / 答题卡 / 教师修正）

值日 ​

  • 今日值日岗位与完成状态
  • 本周轮换安排

班级资源 ​

  • 教师下发的资料按科目分类查看与下载

留言 ​

  • 与班主任 / 任课教师一对一留言
  • 消息留痕，教师回复后可在会话中查看历史

账号与安全 ​

  • 微信授权登录，凭 6 位邀请码绑定孩子
  • 多孩切换；解绑需教师确认
  • 未成年人信息按隐私政策最小必要原则收集
