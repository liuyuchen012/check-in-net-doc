使用手册 ​

按角色速查：教师 / 班主任 · 教务与机构管理员 · 家长 · 平台运营方。

教师 ​

上课前 ​

  1. 打开一体机大屏（桌面端大屏模式），确认班级与签到码
  2. 需要签到时在后台「签到」创建签到码，学生扫码后名字实时上屏
  3. 需要点名时在「点名」选择场次模式（随机加权 / 顺序 / 指定）

下课后 ​

  1. 核对课时划消流水（自动扣减，异常可手工修正并填备注）
  2. 记录积分变动（打卡 / 点名 / 值日 / 答题卡自动入流水）
  3. 更新值日完成情况

考试与阅卷 ​

  1. 「试卷」新建或导入试卷 → 配置答题卡版面 → 打印（或批量生成一人一张）
  2. 学生作答后拍照上传（App 或网页端动态扫卡）
  3. 在「批改」页逐题复判：看识别内容、AI 建议分，快捷记分键改分
  4. 「确认出分」后成绩计入统计；需要时导出 CSV

快捷记分键按 0 → 满分间隔 0.5 分布；分差较大的答卷支持双判与仲裁。

班主任 ​

事项入口说明
通知发布通知支持定时发布，家长端带已读回执
值日轮换值日按周 / 按日轮换生成，可手工调整
座位编排座位拖拽调座；一键随机换座自动留存快照
家长绑定学生批量生成 6 位邀请码并导出 CSV 打印发放
留言处理留言家长留言集中处理，回复留痕

教务 / 机构管理员 ​

  1. 班级与学生：建班、批量导入学生、维护学号条码
  2. 课程表：维护作息与班级课表，导入导出 ClassIsland 档案，一键推送到教室一体机
  3. 设备：注册打卡设备与一体机，查看在线状态
  4. 用户与权限：创建子账户（owner / teacher），按角色分配权限点
  5. 成绩：按班级查看总分与得分率分析，导出 CSV 交教务归档
  6. AI 设置：配置 AI 地址与密钥（或使用平台额度）、提示词模板、图像外发开关、查看调用日志
  7. 授权：查看区域授权状态与到期时间；主账号可签发子用户与邀请码

家长 ​

  1. 用教师发放的 6 位邀请码绑定孩子（多孩可切换）
  2. 查看通知（带已读状态）、值日安排、班级资源
  3. 成绩概览需学校开启后可见（默认关闭，保护隐私）
  4. 可直接给老师留言，沟通留痕

平台运营方 ​

事项入口
新建机构区域「区域管理」创建区域
开通 / 续期机构生成 AGRR- 激活码发给机构主账号
充值平台 AI生成 AGRT- 额度码（金额 → 模型 token 折算）
查看区域用户「区域管理」查看本区域用户并启停账号
远程存储服务端配置 WebDAV 地址与密钥（平台级，所有机构数据统一上传）

教学之外：手写数据闭环（平台侧） ​

生成训练卡 → 学生誊抄 → 扫回切行 / 切单字 → 本地 OCR 自动筛选可用样本 → 抽查纠正 → 导出训练集。用于持续微调自有手写识别模型，识别越用越准。
