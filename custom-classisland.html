定制版 ClassIsland（AgoraIn 集控客户端） ​

一句话：这是基于 ClassIsland 的 AgoraIn 定制分支， 在原有课表 / 提醒 / 界面能力之上，内置了 AgoraIn 集控客户端 —— 教室一体机装上它， 就能接收教师端下发的通知、语音播报、锁屏、电源控制、课表推送与呼叫提醒。

许可：GPL-3.0 开源（ClassIsland 衍生作品，源码随包提供，详见开源许可声明）。

一、和"一体机插件"有什么区别？ ​

一体机插件（.cipx）定制版 ClassIsland（本页）
形态ClassIsland 的插件，装在你现有的 ClassIsland 里一整个 ClassIsland 客户端（解压即用）
能力呼叫接收（弹窗 + 朗读）、课表同步呼叫接收 + 完整集控指令：通知 / 播报 / 锁屏 / 解锁 / 网页 / 应用启停 / 课表推送 / 日志上传 / 设置下发 / 休眠 / 重启 / 关机
关于页—显示 AgoraIn 品牌信息与定制版本号
适合已经有一套 ClassIsland 在跑，只想加联动教室一体机想一次装好、被平台统一管控

两者可以共存：插件负责你原有 ClassIsland 的呼叫联动；定制版适合新装教室机。

二、下载与安装 ​

  1. 打开下载中心，下载 定制版 ClassIsland（AgoraIn 集控客户端）；
  2. 解压到任意目录（如 D:\AgoraInClassIsland）—— 自包含打包，无需安装 .NET 运行时；
  3. 双击 ClassIsland.Desktop.exe 启动（首次启动按向导完成基础设置即可）。

系统要求：Windows 10 1809+（教室一体机 / 电子白板 / 普通 PC 均可）。

三、连接到 AgoraIn 集控平台 ​

  1. 打开客户端 → 设置 → 集控 → 加入管理；

  2. 在「AgoraIn 集控平台（定制版）」一栏填写服务器地址：

    https://agorain.615mc.cn

    （连接密码：平台未启用连接密码时留空即可；如机构自行部署了服务端，填你自己的地址）

  3. 点「连接到 AgoraIn 集控平台」，看到「已登记」即接入成功；

  4. 回到教师端 → 教学模式 →「集控平台」，设备列表会出现这台教室机（名称形如 ClassIsland-<计算机名>）， 此后即可对其下发指令，指令历史里能看到执行回执。

四、支持的集控指令 ​

指令教室端行为
通知弹窗 / 自定义消息顶部提醒横幅显示文本
语音播报横幅 + 中文语音朗读
锁定屏幕 / 解锁屏幕锁屏（解锁需本机手动操作，Windows 不允许程序自动解锁）
打开网页 / 启动应用 / 结束应用默认浏览器打开网址 / 启动指定程序 / 按进程名结束
推送课表档案 / 刷新课表重新拉取平台下发的课表并刷新显示
上传日志打包客户端日志到 LogUploads\*.zip，回执里带上路径（排障用）
下发设置记录并回执（具体键值映射按机构策略配置）
休眠 / 重启 / 关机系统电源操作（首次上线前建议先在 1 台机器演练）
呼叫提醒（下课传唤 / 上课应急 / 待下课通知）提醒横幅 + 语音朗读，应急类型置顶

五、关于页的品牌信息 ​

定制版的「设置 → 关于」中新增了 AgoraIn 定制版 卡片：显示 AgoraIn 标志、定制版本号、 集控客户端说明与平台入口链接；同时保留上游 ClassIsland 的版本、开源许可与贡献者信息。

六、源码与许可 ​

  • 本定制版是 ClassIsland 的衍生作品，整体以 GPL-3.0 发布，源码随二进制提供；
  • 与 AgoraIn 服务端（闭源商业软件）之间只通过 HTTP 协议对接，双方不链接彼此代码；
  • 上游项目：https://github.com/ClassIsland/ClassIsland（同样为 GPL-3.0）；
  • 完整说明（含服务端集控插件、第三方库许可、常见误解澄清）：开源许可声明。

常见问题 ​

Q：客户端显示"已连接"但收不到指令？ 先确认教师端「集控平台」里这台设备是在线的；若客户端所在机器装了代理软件，请把平台地址加入直连（程序已按直连方式访问内网地址）。

Q：能用上游官方版 ClassIsland 吗？ 可以，但官方版没有集控指令通道；要接收通知/播报/锁屏/电源控制等，需要用本定制版（或等待后续插件化支持）。

Q：解压后提示缺少运行库？ 本包为自包含发布，正常情况下不需要任何运行时；若被安全软件拦截，请放行 ClassIsland.Desktop.exe。
