服务端与授权 ​

服务端是 AgoraIn v4 的唯一在线节点：一套部署同时服务多所机构（多区域 / 租户隔离）， 机构自助注册后由平台方颁发激活码开通。

初始化 ​

首次部署后访问站点，或直接调用：

bash
curl -X POST http://<host>:5250/api/v4/auth/setup \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"******","email":"admin@example.com"}'

初始化完成后 /api/v4/setup/status 返回 {"needsSetup":false}。 管理面板登录页在未初始化时也会给出创建管理员的向导。

三级编码体系 ​

前缀名称颁发方用途
AGRN-服务器激活码授权方（离线签发）服务器级商业授权，绑定机器指纹、限制设备数与到期时间
AGRR-区域激活码主区域开通 / 续期某个机构（区域）；未激活区域仅主账号可登录
AGRT-AI 额度码主区域为机构充值平台 AI 额度（余额以人民币计价，跨模型通用）

多区域（租户）体系 ​

  • 注册：机构注册（mode=region）创建区域与主账号；家长可凭邀请码加入（mode=join）
  • 登录：用户名@区域（主区域为 @manager；不带 @ 按主区域处理）
  • 数据隔离：班级、学生、打卡、课时、课表、试卷、成绩等全部按区域过滤
  • 区域功能开关：AI 功能 / 阅卷与出分 / 答题卡识别与批改 / 设备注册 / 课表管理 / 子用户 / 家长邀请
  • 账号管理：区域管理页可查看本区域用户并禁用 / 启用账号

AI 与额度 ​

场景计费
机构使用平台 AI按实际 token 扣减额度（DeepSeek / Mimo 按模型折算，余额以元计价）
机构自配 AI 密钥不受平台额度限制，费用由机构自行承担
本地识别（客观题涂卡、填空手写）零 token，不产生任何费用

配置优先级：appsettings 默认 → 主区域全局覆盖 → 区域独立配置（最高）。 每个机构都可以在「AI 设置」中配置自己的地址、密钥、模型与提示词模板，或一键清除恢复平台默认。

图像外发

「AI 图像外发」开关关闭后，平台不会向第三方大模型发送任何作答图像， 主观题自动转为教师人工批改。该开关按机构控制。

加密远程存储 ​

  • 答题卡原图与教学资料使用 AES-256-GCM 认证加密（被篡改的文件读取时会被拒绝）
  • 通过 WebDAV 上传远程磁盘，路径形如 {根目录}/agorain/{区域}/{类别}/
  • 服务器只保留按需缓存（LRU），且只淘汰已确认上传成功的本机副本
  • 远程不可用时自动排队补传，不影响本地使用

邮件（SMTP） ​

用于注册验证码与忘记密码。在「设置」中配置服务器、端口、发件人、密码与 SSL， 并可直接发送测试邮件。服务端内置发信频率限制（同一邮箱 / IP 的冷却与每日上限）。

安装包分发（下载中心） ​

官网的下载按钮指向平台自己的分发接口，安装包存放在数据目录的 downloads/ 下：

接口鉴权用途
GET /api/v4/downloads匿名清单：名称 / 平台 / 版本 / 大小 / SHA256 / 下载地址
GET /api/v4/downloads/{slug}匿名下载文件（支持单段 Range 断点续传）
HEAD /api/v4/downloads/{slug}匿名只取大小与指纹
GET /api/v4/downloads/guard匿名反多线程策略与当前占用快照（排障）
POST /api/v4/downloads/{slug}运营方上传 / 覆盖安装包（multipart，name/platform/version/note/order 可选）
DELETE /api/v4/downloads/{slug}运营方删除安装包
  • 官网按钮用的固定 slug：桌面端 desktop-win-x64、移动端 android-apk
  • 直接把文件放进 downloads/ 也能用（slug 取文件名去扩展名）；downloads/manifest.json 负责展示名、版本与排序

反多线程下载（默认开启，appsettings.json 的 Downloads 段可调）：

策略默认值作用
同一 IP 并发连接3超过直接 429，防止开几十条连接抢带宽
同一 IP 对同一文件并发2分段下载器叠加不出速度
每分钟 Range 请求6 次超预算按 IP+文件临时封禁（默认 5 分钟）
单连接带宽上限8192 KB/s多线程总速度被"每线程上限 × 允许并发"封顶

正常浏览器/手机下载只占 1 条连接、至多 1~2 次 Range 请求，不受影响。

更新检查 ​

服务端代理 GitHub Releases 查询版本，客户端「设置 → 更新检查」可查看新版本并跳转下载 （30 分钟成功缓存 / 5 分钟失败缓存）。
