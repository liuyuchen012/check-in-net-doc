## v3.2 是什么

AgoraIn v3.2 在一个窗口内提供**大屏模式**（课堂签到打卡）与**控制模式**（呼叫面板、课时划消与排课、
集控平台），配套集控服务器与移动端 App，并提供 **ClassIsland 联动插件**：教室一体机接收教师端呼叫，
以置顶弹窗 + 中文语音朗读提醒。

| 模块 | 说明 |
| --- | --- |
| 大屏模式 | 班级电子白板大屏签到，点击学生姓名完成打卡，前三名金 / 银 / 铜高亮 |
| 控制模式 | 呼叫面板（待下课 / 应急 / 传唤）、课时划消与排课、集控平台 |
| 集控服务器 | 多设备数据集中管理，Web 管理面板，平台配置持久化自动重连 |
| ClassIsland 插件 | 一体机端接收呼叫，置顶弹窗 + 中文语音朗读 |
| 移动端 | 微信小程序 + Android + iOS / macOS 客户端 |

技术栈：桌面端 WPF（.NET 10）· 移动端 .NET MAUI · 服务端 ASP.NET Core · 数据库 SQLite。
